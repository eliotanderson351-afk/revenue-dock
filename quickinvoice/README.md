# QuickInvoice

A polished browser-only invoice maker for freelancers and small businesses.

## MVP
- Seller and customer details
- Dynamic line items
- Tax and discount controls
- Live totals
- Print / Save as PDF
- Local draft persistence

## Monetization experiment
Free local invoice; paid hosted invoice links, recurring invoices, client portals, templates, branding and payment integrations later.

## Run
Open `index.html`.
