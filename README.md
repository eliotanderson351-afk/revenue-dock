# Revenue Dock

Revenue Dock is a local-first quote and proposal builder for freelancers and small studios.

## What it does

- Build a client-ready offer with services, quantities, pricing and deposit terms.
- Preview the client-facing proposal live.
- Save drafts locally in the browser.
- Print or export the proposal to PDF.
- No account or server required for the MVP.

## Run

Open `index.html` in a modern browser. The app is intentionally dependency-light and stores drafts locally.
