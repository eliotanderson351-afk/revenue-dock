# Revenue Dock — Indie Product Lab

Revenue Dock is the main product-lab homepage for a set of focused MVP experiments.

> One product per experiment. Build fast. Measure what people actually use.

## Products

Each product has its own GitHub repository and its own independent page, design, and browser-side logic:

- Revenue Dock — quotes and proposals
- LinkPay Mini — focused payment pages
- Waitlist Spark — waitlist and referral growth
- Leadboard Lite — lightweight CRM workflow
- PricePilot — package pricing
- ReviewDrop — testimonial collection
- Campaign Kit — UTM campaign links
- Pixel Polish — browser image optimization
- QuickInvoice — freelancer invoicing
- ApplyTrack — job application pipeline
- Signature Studio — professional email signatures

## Structure

The revenue-dock repository contains only the Revenue Dock project itself.

The other products are intentionally not nested inside this repository. Each lives in its own repository so it can be developed, tested, versioned, and deployed independently.

## Product strategy

Each project starts as a fast, useful MVP. Hosted accounts, analytics, integrations, team features, and paid tiers should be added only when the underlying workflow proves useful.
